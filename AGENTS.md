# Правила проекта

- Не добавлять атрибуты `aria-*`, включая привязки Vue и объекты атрибутов.
- Не вводить свойства компонентов для передачи этих атрибутов.
- Для навигации использовать RouterLink из vue-router. Автоматически добавляемый им атрибут активной ссылки допустим; вручную атрибуты `aria-*` не добавлять.
- Для тестов использовать текст, обычные HTML-атрибуты, нативные label и структуру компонентов.
